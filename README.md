# 🐧 PCA & Clustering Analysis – Palmer Penguins

## 📌 Overview

This project applies **Principal Component Analysis (PCA)** and **unsupervised clustering techniques** to analyze morphological differences between penguin species.

**Dataset:** Palmer Penguins (344 observations)

---

## 🎯 Objectives

- Reduce dimensionality using PCA
- Identify natural groupings using clustering
- Compare clustering results with real species labels

---

## ⚙️ Methods

- Data Cleaning & EDA
- Correlation Analysis
- PCA (Standardized Data)
- Hierarchical Clustering (Ward)
- K-Means Clustering
- Validation: Silhouette Score & Accuracy

---

## 📊 Key Results

- 2 principal components explain **88% of variance**
- Optimal clusters: **k = 3**
- Hierarchical Clustering Accuracy: **96.7%**
- K-Means Accuracy: **91.9%**

---

## 🔍 Insights

- PC1 represents **body size**
- PC2 captures **bill morphology**
- Gentoo species is perfectly separable
- Adelie & Chinstrap show partial overlap
